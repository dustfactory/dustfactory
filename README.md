### 소개

- 이름은 **먼지 (meonji)**, GitHub 아이디는 `meonji-mon`입니다.
- 모바일 앱, macOS·Windows 도구, 작은 게임을 직접 만듭니다.
- 코딩 에이전트(Codex, Claude Code)를 쓰는 작업 방식과 규칙을 [agent-harness](https://github.com/meonji-mon/agent-harness)로 공개하고 있습니다.
- 브랜드 로고와 제작 규격은 [MEONJI-Brand](https://github.com/meonji-mon/MEONJI-Brand)에서 관리합니다.
