## 소개

먼지(meonji)입니다. 필요한 것을 직접 만들어 씁니다.

- 휴대폰 앱부터 데스크톱 도구, 가벼운 게임까지 만듭니다.
- 코딩 에이전트와 함께 일하는 방식과 규칙을 [agent-harness](https://github.com/meonji-mon/agent-harness)에 정리합니다.
- 로고와 제작 규격은 [MEONJI-Brand](https://github.com/meonji-mon/MEONJI-Brand)에서 관리합니다.
